# JSON Questions Integration

The webapp now supports loading questions from JSON files generated by the extraction pipeline.

## How It Works

1. **Extraction Pipeline** (`scripts/`):
   - Extracts questions from PDFs/images
   - Saves to `scripts/output/{year}/{source}-{date}.json`

2. **API Routes** (`app/api/questions/`):
   - `GET /api/questions` - Returns all questions from JSON files
   - `GET /api/questions/[id]` - Returns a specific question by ID

3. **Frontend Pages**:
   - `/questions` - Lists all questions from JSON files
   - `/questions/[id]` - Shows question details with LaTeX rendering
   - `/sessions/[questionId]` - Canvas page with question panel

## Features

- ✅ Automatic loading from JSON files
- ✅ LaTeX rendering for questions and options
- ✅ Source filtering support
- ✅ Refresh button to reload data
- ✅ Error handling and empty states
- ✅ Metadata display (subject, topic, page number)

## Usage

1. **Extract questions**:
   ```bash
   cd scripts
   npm run extract papers/2025/jee_advanced_2025.pdf --source "JEE Advanced 2025"
   ```

2. **View in webapp**:
   - Navigate to `/questions` to see all extracted questions
   - Click on a question to see details with LaTeX rendering
   - Use the canvas page to work on questions

## API Endpoints

### Get All Questions
```
GET /api/questions?source=JEE Advanced 2025&year=2025
```

Response:
```json
{
  "questions": [...],
  "sources": ["JEE Advanced 2025"],
  "total": 50
}
```

### Get Single Question
```
GET /api/questions/{id}
```

Response:
```json
{
  "id": "jee-advanced-2025-q1",
  "title": "...",
  "question": "...",
  "latexQuestion": "...",
  "options": {...},
  "latexOptions": {...},
  ...
}
```

## Data Structure

Questions follow this structure (matching the extraction output):

```typescript
{
  id: string
  title: string
  question: string              // Plain text
  latexQuestion?: string         // LaTeX version
  difficulty: 'Easy' | 'Medium' | 'Hard'
  options: {
    A: string
    B: string
    C: string
    D: string
  }
  latexOptions?: {
    A?: string
    B?: string
    C?: string
    D?: string
  }
  metadata: {
    source: string
    page: number
    questionNumber: number
    subject?: string
    topic?: string
  }
}
```

## Troubleshooting

### Questions not showing?
- Check that JSON files exist in `scripts/output/{year}/`
- Verify the API route is accessible: `http://localhost:3000/api/questions`
- Check browser console for errors

### LaTeX not rendering?
- Make sure `katex` is installed: `npm install katex @types/katex`
- Check that `latexQuestion` and `latexOptions` fields exist in JSON

### API errors?
- Ensure the scripts directory structure matches: `scripts/output/{year}/*.json`
- Check file permissions
- Verify JSON files are valid JSON
